# 云岚 CloudBrew C1 便携咖啡机 深度评测：露营党新宠，还是智商税？

> 数码体验站 · 评测组 · 2026-09-18 · 阅读约 6 分钟

过去一个月，我们把这台巴掌大的便携咖啡机带去三趟露营、两次办公室通勤，累计萃取一百多杯。它到底值不值得买，这篇一次说清。

## 基本参数

| 项目 | 规格 |
|---|---|
| 萃取方式 | 15 Bar 电动泵压，兼容胶囊与粉仓 |
| 电池容量 | 4000mAh，满电可连续萃取约 **42 杯** |
| 加热 | 冷水起冲，约 3 分钟出一杯 60ml Espresso |
| 整机重量 | 620g（含水箱） |
| 水箱 | 80ml |
| 首发售价 | **¥899**（含一盒 10 颗装胶囊） |

## 好用的地方

最惊喜的是**续航**。官方标的 42 杯不虚标，一次满电撑过了三天两夜露营，中途没找过充电宝。15 Bar 泵压在便携机里算高的，油脂层（Crema）比预期厚，入口不寡淡。

其次是加热逻辑，不用预热，冷水直冲，3 分钟出杯，早上赶时间友好。

## 不足

- 水箱只有 80ml，做美式要分两次接水
- 第三方胶囊偶有漏粉
- 620g 揣兜里偏沉，更适合放包里

## 一句话总结

续航和油脂真香，水箱小和重量是真缺点；¥899 这价位，重度露营用户值得，轻度用户可等降价。按需决定，别被"便携"两个字冲昏头。
